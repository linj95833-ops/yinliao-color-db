饮料换装 · 程序与数据库交付包
============================================================
打包时间：2026-11-11    版本：55 品牌 / 55 张包装图 / 55 份实测多色档案

本压缩包是「解压即可运行」的完整离线工程：程序 + 数据库 + 图片库 + 配置 +
网页前端 + 55 品牌逐个调好的贴图参数，全部在里面。照片只在本机处理，不上传公网。


一、最快开始（Windows）
------------------------------------------------------------
1. 把整个压缩包解压到一个没有中文/空格也不强制、但尽量简单的目录，
   例如 D:\drink-wrap\ 。解压后应能看到 start.bat、beverage_color_db\、data\ 等。
2. 电脑需已安装 Python 3.10+（安装时勾选 Add Python to PATH）。
3. 双击 start.bat。
   - 第一次会自动建 .venv 并安装依赖（需联网一次，约 1-3 分钟）；
   - 之后自动打开浏览器 http://127.0.0.1:8765/ ；
   - 之后再用就是秒开，完全离线。
4. 上传/拍照 → 选人像 → 点「开始匹配」，也可以搜索并指定饮料；
   结果图可长按 / 右键保存。

其它启动方式：
   start.bat --check        只做环境自检（打印品牌/图片/档案数量 + 试跑匹配）
   start.bat --port 9000    换端口
   start_lan.bat            开放局域网，手机直连（若被防火墙拦，用下面这个）
   start_mobile.bat         手机访问「转发模式」，绕开 Windows 防火墙限制（推荐）
   start.bat --cli match --photo examples/portrait_sample.png --compose
                            透传原命令行，全部 CLI 子命令都能这样用

macOS / Linux：终端执行  ./start.sh   或   python3 start.py --lan


二、手机上打开
------------------------------------------------------------
1. 双击 start_mobile.bat（或 start_lan.bat）。
2. 手机与电脑连「同一个 Wi-Fi」，用手机浏览器打开窗口里打印的地址
   （形如 http://10.21.196.178:8765/ ，IP 以实际输出为准）。
3. 也可以打开 report/phone_access.html 扫二维码（服务启动时自动生成，
   换 Wi-Fi / IP 变化后重新运行 scripts/make_phone_qr.py 即可）。
4. 校园网/公司网常有 AP 隔离，手机连不上时改用「电脑开个人热点，手机连热点」。
   电脑休眠、防火墙拦截、IP 变化是最常见的三个原因。


三、包里有什么
------------------------------------------------------------
  beverage_color_db/     全部 Python 源码（建库/提色/多色匹配/衣服分割/包装贴图/Web 服务）
  config/brands.yaml     55 个品牌清单（key、中文名、别名、参考色）
  config/brand_wrap.yaml 55 个品牌逐个调好的贴图参数（裁切/焦点/清晰度/形变等）
  config/*.yaml          图源、官网、种子色等配置
  data/catalog.db        SQLite 数据库：55 品牌 / 55 图片记录 / 55 多色档案 / 271 色特征
  data/images/           55 个 key_中文名 目录，每个 1 张你手动确认过的包装图
  web/index.html         上传、删图重传、指定/随机饮料、风格切换的网页界面
  scripts/               局域网转发、手机二维码生成
  examples/              测试用人像
  report/brand_gallery.html  55 款包装预览页
  requirements.txt / start.*  依赖清单与一键启动脚本
  README.md / ATTRIBUTION.md 完整技术文档与图片署名清单
  MANIFEST.txt           本包逐文件清单 + SHA256，可用于完整性核对

未打包：.venv（277MB，且与本机 Python 路径绑定，换机器不可直接搬）、
临时缓存 data/cache、以及所有含人像的调试/对比图（属私人数据，运行时会重新生成）。


四、常用命令（在解压目录里）
------------------------------------------------------------
  .venv\Scripts\python.exe -m beverage_color_db.cli match --color "#E60012"
  .venv\Scripts\python.exe -m beverage_color_db.cli match --color "#E60012,#004B93"
  .venv\Scripts\python.exe -m beverage_color_db.cli match --photo my.jpg --compose --brand kangshifu
  .venv\Scripts\python.exe -m beverage_color_db.cli scan        # 换图/加图后重算颜色
  .venv\Scripts\python.exe -m beverage_color_db.cli reconcile   # 核对磁盘图片与数据库
  .venv\Scripts\python.exe -m beverage_color_db.cli serve --lan # 网页服务

动过 config/brand_wrap.yaml 后要重启服务才会生效（参数有缓存）。
图片目录规则、增删品牌、算法说明、署名信息见 README.md。


五、注意
------------------------------------------------------------
- 依赖第一次安装需要联网；若目标机器完全不能联网，请先在可联网机器执行
  pip download -r requirements.txt -d wheels\ ，把 wheels 目录一起带过去，
  再用 pip install --no-index --find-links wheels -r requirements.txt 安装。
- data/images 里的包装图由使用者自行提供并确认授权，本项目不对其授权背书；
  .gitignore 已刻意排除这些图片和含人像的结果页，请勿直接推送到公开仓库。
- 衣服分割是启发式色调分割，不是人体解析模型；源图没有的细节无法凭空生成。
  想要更清晰，优先换高清正面包装图，或调 config.py 的 COMPOSE_MIN_SHORT_EDGE。
